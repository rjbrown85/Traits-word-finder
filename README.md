# Character Word Finder

A self-contained Grade 5 dictionary and thesaurus with 336 word entries and 42 starting-word families.

## Features

- Search familiar English words, related vocabulary, or meanings in English, Korean, Swedish, or Simplified Chinese.
- Choose language help at the top. Simple translated meanings and directions appear beneath English text, while vocabulary words stay in English.
- The language choice stays selected in the current browser. Example sentences remain in English as reading models.
- Browse feelings and character traits, or use the alphabetical index.
- Compare emotional intensity where appropriate and explore differences in meaning.
- Read simple definitions, example situations, and prompts for finding story evidence.
- Save up to six words in a browser-local tray and compare or copy them.
- Use the responsive, keyboard-accessible interface on desktop, tablet, or phone.

## Use

GitHub Pages serves `index.html` from the root of `main`. Download and open `index.html` to use the dictionary offline. The file includes its own styles, logic, and word bank. No installation is needed.

Saved words stay in the current browser when local storage is available. No student names or responses are collected or transmitted. Example situations are original instructional examples, not quotations from books. Intensity comparisons depend on context, and related words are not always interchangeable.
